## 如何理解这些示例

- 这些是已有笔记的公开副本，不是针对当前版本重跑或为展示而编造的模拟输出。模型、插件版本、运行参数、耗时及 `qualityPassed` 均未在笔记中记录，无法确认；也无法确定公开整理之前是否经过人工修改。不同模型和设置不会保证生成相同结果。
- 开发记录记载，两篇论文笔记来自早期项目的实际运行；视频笔记的具体运行记录尚未找到，不能据此确认生成方式或版本。
- 论文笔记中“第 N 行”是当时提取文本的行号，不一定与原文 PDF 行号对应。思维链示例的数据和引用可对照 arXiv v2：58.1% 使用外部计算器；仅思维链为 56.5%。部分措辞与 2022 年实验条件有关，并不构成对当前所有模型的结论。
- 已抽查情绪智力论文摘要的一处引用并恢复原文中的疑似笔误；其他事实和引文未逐条核验。视频笔记使用自动字幕，抽查了其中三条引文并按字幕近似校正时间戳，未对照音频；其余时间戳及逐字引文尚未逐条核验。请以原文为准。
- 为便于公开阅读，移除了两篇论文笔记中指向私人笔记的链接，将它们之间的 Obsidian 双链改为普通 Markdown 链接，并补充上述声明、修正一处引文、说明计算器条件及按自动字幕近似校正三处时间戳；没有修改 Obsidian 原件。
